# Third-Party Notices

Kaizen Runtime is a clean-room implementation. No third-party source code
is copied into this package. Patterns and architectural ideas from prior
art in the agentic-AI space were studied and reimplemented from scratch.

If in future phases a specific open-source dependency is adopted, its
license and copyright notice will be recorded here.

## Runtime dependencies

- `typescript` — Apache 2.0 (Microsoft)
- `vitest` — MIT (Vitest contributors)

Full transitive dependency license report is regenerated on every release
via `pnpm licenses list` and archived alongside the release notes.
